# Resume & Job Opportunities Platform

## Run
1. Extract the project.
2. Open Git Bash in the project folder.
3. Run:
   npm install
   npm start

## Main panels
- User Panel: dashboard, resume builder, templates, preview, profile, jobs, saved jobs.
- Admin Panel: dashboard, manage jobs, add job, users, applications.

## Job matching
The frontend demo reads resumeData from localStorage and compares resume skills with each job's required skills to produce a match percentage.

## Notes
This is a frontend/demo implementation. Authentication, MongoDB, Express APIs, real job feeds, email reset and production job applications should be connected to a backend for a complete MERN system.
